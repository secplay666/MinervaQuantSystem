# ADR-006：示范策略、基准与验证方案

- 状态：已接受
- 日期：2026-09-26
- 关联：ARCHITECTURE.md §12、§19 阶段 2；ADR-002

## 决定

### 示范策略

示范策略的用途是验证回测引擎，**不构成投资建议**。定义如下：
- **信号**：120 日动量，即 `hfq[t−20] / hfq[t−140] − 1`，按交易日计算，跳过最近 20 个交易日。
- **选股**：得分最高的 50 只，等权持有，每月最后一个交易日收盘后调仓。
- **股票池**，同时满足以下条件：
  - 属于沪深主板、创业板或科创板（北交所默认不纳入）；
  - 当日有日线；
  - 上市满 250 个交易日；
  - 信号窗口内至少 90% 的交易日有日线；
  - 近 20 个交易日日均成交额 ≥ 1,000 万元；
  - 不处于已知的风险警示状态（深市按带日期的区间判断；沪市、北交所状态未知，不排除）。
- **排名相同**时按代码排序，保证结果可复现。
- **参数**：初始资金 100 万元；佣金万 2.5、每笔最低 5 元；印花税和过户费按法定费率。

### 基准

- **主基准**：等权全收益基准。股票池规则与策略相同，同一调度日再平衡，按后复权价格计算，不计费用。
- **参考基准**：沪深 300、中证 500。它们是**价格指数，不含分红**，与全收益的策略比较时会高估超额收益，约为指数股息率，报告中已标注。

### 验证方案

- **样本**：样本内 2020-07 至 2023-12；样本外 2024-01 至 2026-09，只评估一次。
- **压力测试**：佣金加倍；滑点 20bp；延迟到 T+2 开盘成交；退市按 0 元结算。
- **引擎正确性检验**（均已加入自动化测试）：
  - 每日会计恒等式按"分"精确成立；账本可重放；
  - 截断未来数据、扰动未来数据，历史结果都完全不变；
  - 相同输入的结果确定，与输入行的顺序无关；
  - 无交易日的净值变化等于持仓的后复权收益；
  - 固定数据集的逐行回归（`tests/test_bt_regression.py`）。

## 首次结果（2020-07-01 至 2026-09-24，数据版本 `d0a2a1f8…`）

| 设定 | 累计收益 | 年化收益 | 最大回撤 |
|---|---:|---:|---:|
| 基准设定 | −59.71% | −13.62% | −72.70% |
| 佣金加倍 | −60.66% | −13.95% | −72.85% |
| 滑点 20bp | −62.13% | −14.48% | −73.15% |
| T+2 开盘成交 | −58.86% | −13.33% | −71.15% |
| 退市按 0 元结算 | −59.69% | −13.61% | −72.68% |
| 等权全收益基准 | +69.04% | +8.82% | −32.80% |

- 样本内累计 −44.2%，样本外累计 −27.7%，两段都亏损。
- **引擎验证**：用独立方法计算的理想化组合为 −57.9%（调仓日收盘成交、不计费用、不取整）。引擎结果与之的差距正好对应费用、整手取整和开盘价成交。在 1,225 个无交易日中，净值与持仓收益推算值完全一致。
- **退市按 0 元结算反而略好**：这是路径分叉造成的。两次运行在结算日之前的成交完全相同，结算当日净值正好低 1,764 元；此后下单股数不同，期末差额很小。
- **结论**：引擎通过验证；该动量策略在样本期内显著跑输，与"A 股中期动量弱、短期反转强"的普遍观察一致。它不应作为策略研究的起点，只作为引擎的回归基准。

## 复审条件

更换示范策略、引入全收益指数数据（如 H00300、H00905），或补齐沪市、北交所 ST 历史后复审。
