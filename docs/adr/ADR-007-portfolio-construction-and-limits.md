# ADR-007：组合构建、约束与风险限额

- 状态：已接受（阶段 3）
- 日期：2026-09-26
- 关联：ARCHITECTURE.md §5.6、§5.7、§11、§20；ADR-002、ADR-009

## 背景

ARCHITECTURE §20 为 ADR-007 预留了“账户规模对应的仓位、流动性和回撤限制”。阶段 3 的多因子策略需要把得分变成满足约束、可以解释的目标权重。用户确定：规则法作为默认，同时实现均值-方差优化，两者对比。

## 决定

### 1. 研究基准规模

- **研究基准资金 1,000 万元，持股约 100 只**。每只目标约 10 万元，一手门槛基本不影响选股，因子研究的结论不会被“买不起高价股”扭曲。
- **100 万元（约 50 只）作为压力测试**单独报告。100 万元、100 只时，股票池前 1,800 只中约 16% 的股票一手就超过目标金额（2026-09-24），用替补会让组合不自觉地偏向低价股。
- 报告始终列出低价股（收盘价 < 10 元）权重，并与股票池对比。

### 2. 规则法（默认，`portfolio/construction.py`）

| 规则 | 默认值 | 说明 |
|---|---|---|
| 持股数 N | 100 | |
| 换手缓冲 | 1.5N | 已持有且排名在 1.5N 以内的股票保留 |
| 行业持股数 | 基准权重 ± 5% | 基准为股票池等权；各行业下限之和超过 N 时逐步放宽并记录 |
| 一手替补 | 1.2 倍 | 一手金额超过目标金额 1.2 倍的股票剔除，由下一名替补并计数 |
| 权重 | 等权 | 可选按得分倾斜 1 + κz |
| 单股上限 | min(2%, 10% × 20 日平均成交额 × 1 天 / 净值) | 超出部分反复截断并重新分配；无法满仓时保留现金 |

### 3. 均值-方差优化（`portfolio/optimizer.py`）

- **目标**：最大化 α'w − λ·主动风险 − 摊销后的交易成本。
  - α = IC × σ × z：IC 默认 0.05，σ 为风险模型给出的个股波动，z 为候选股票内标准化后的综合得分。
  - λ 默认 20。在样本内的冒烟运行中，对应的事前跟踪误差为 4.4%–6.3%（均值 5.4%）。
  - 交易成本按当日适用的费率计算，分摊到 6 个月的预期持有期。
- **约束**：
  - 满仓；
  - 单股上限同规则法；
  - 当日无行情的股票权重冻结；已不在股票池的持仓强制卖出；
  - 行业主动权重 ±5%，规模暴露 ±0.5 个标准差；
  - 单边换手 ≤ 50%，强制卖出的部分另计。
- **候选**：得分前 400 只、当前持仓和强制卖出股票的并集。
- **求解**：OSQP。
  - 先用 sigma = 1e-4，没有收敛时改用 rho = 1.0 再求一次。这是在真实调仓上调出来的：带换手约束时默认参数经常达到迭代上限。
  - 只直接接受“solved”；“solved inaccurate”或达到迭代上限的解，所有约束都满足到 1e-5 以内才接受。
  - 小于 0.1% 的权重、一手超过目标的股票置零后再求解一次。
- **回退**：依次去掉换手预算 → 行业和风格约束放宽一倍 → 去掉风格约束 → 改用规则法。每次调仓记录用了哪一级。

### 4. 风险模型（`portfolio/risk_model.py`）

| 项目 | 设定 |
|---|---|
| 暴露 | 申万一级行业哑变量（相当于截距），加规模、12-1 动量、特质波动、换手、BP、EP、成长、杠杆、贝塔；股票池内按流通市值加权标准化，缺失记 0；每个月末计算一次，下月内固定 |
| 因子收益 | 每日加权最小二乘（权重 √流通市值），使用前一个月末的暴露；单日收益截断在 ±25% |
| 因子协方差 | 指数加权，半衰期 90 个交易日，窗口 504 天，× 21 折算为月 |
| 特质风险 | 指数加权，半衰期 60 天；少于 40 个观测时用同市值十分位的中位数，并按 n/(n+60) 收缩 |
| 起点 | 第 60 个交易日起的每个月末，保证 2021 年初第一次调仓时已有一年左右的因子收益 |

### 5. 下单与风控

- 组合构建只给出目标权重。下单股数、现金缓冲 0.5%、调仓容差带、先卖后买、涨跌停、T+1、参与率上限等仍按 ADR-002 执行，每次拒单都记录。
- 回撤、日亏损等账户级限额属于阶段 4–5（决策辅助和模拟盘），届时补充到本 ADR。

## 报告

每次回测的 `report.md` 附“风险暴露与归因”一节，并写出对应的 parquet 表：
- 风格暴露：相对股票池等权基准，在股票池内标准化，不做中性化，保留自然符号，如“+规模”表示偏大盘；
- 行业主动权重；
- 集中度：持股数、前 10 大、有效持股数；
- 低价股暴露；
- 行业 Brinson 归因：目标权重，次日开盘建仓，不计费用；
- 优化器诊断：回退级别、事前跟踪误差、换手。

## 复审条件

以下情况出现时复审本 ADR：
- 资金规模变化超过一个数量级；
- 接入模拟盘或实盘；
- 样本外结果显示约束设置不当，例如跟踪误差长期偏离目标。
