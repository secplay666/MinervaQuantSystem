# ADR-004：复权、公司行动与时间点规则

- 状态：已接受（2026-09-26 补齐沪市、北交所 ST 历史，见文末）
- 日期：2026-09-26
- 关联：ARCHITECTURE.md §2、§5.2、§5.3、§9、§12.1

## 背景

2026-09 的审计发现三类时间点问题：

1. `daily_bars_adjusted` 用 `价格 × 新浪 qfq_factor` 计算前复权价，但新浪的 qfq 因子是**除数**（qfq 价 = 原价 / 因子）。结果 77% 的历史行前复权价错误，其中 200 万行偏差超过 20%。
2. 增量模式在已有因子文件时直接跳过下载，8 月以来的除权事件全部缺失。例如 603093 在 2026-08-10 的后复权收益显示为 −30.7%，实际是 +0.5%。
3. 在交易时段内运行会把未收盘的日线永久写入。

## 决定

### 价格与复权

1. 标准层 `daily_bars` 只保存**不复权**价格。`pct_change` 是不复权的收盘价变动，在除权日包含派息送转的影响，不能直接当收益率用。
2. **规范因子是后复权因子 `hfq_factor`**（乘数，复权价 = 原价 × hfq）。它不随新事件改写历史，并与新浪逐位一致。
3. `qfq_factor` 按 `hfq_factor / 最新 hfq_factor` 派生，同样是乘数。前复权价以"最新一次事件"为锚点，**不是时间点数据**：每出现一次新的除权，全部历史前复权价都会整体缩放。
4. 使用规则：
   - 成交、涨跌停、费用、最小交易单位：使用**不复权价**；
   - 收益率、因子计算：使用 **hfq 价格的比值**；
   - 需要前复权价格水平时（如价格过滤），必须以**决策日**为锚点：`hfq_t / hfq_决策日`。不能使用视图中的 `qfq_*` 列，它们只供展示。
5. `effective_date` 即除权除息日，是新基准下的第一个交易日。视图使用 `trade_date >= effective_date` 的 ASOF 连接；已与新浪自身的前复权价逐日核对（1,600 根日线全部在 0.005 元以内）。
6. 视图对缺失因子返回 NULL，并给出 `factor_status`（`ok` / `stale` / `missing`），不再用 1.0 掩盖缺失。

### 复权因子刷新

7. 每次运行为**所有在市证券**重新下载后复权因子（约 5,800 次请求，并发 12，约 6–10 分钟）；已退市证券的因子不再变化，冻结不刷新。
8. 每个因子分区记录 `factor_as_of`，即因子有效期截止的交易日。新浪在除权日当天或之后才发布新因子，不会提前。
9. 刷新后检查历史后复权因子是否被上游修改：出现修订记为警告 `history_stable`，因子本身仍写入，原始层保留旧快照。
10. 没有新浪因子的证券（目前仅 689009 CDR）用新浪历史接口中的除权参考价推导：`步长 = 前收盘价 / prevclose`。该方法已对 6 只股票验证：2020 年以来 62/62 次事件全部命中，单步误差 ≤ 4.4e-4（prevclose 只保留两位小数）；腾讯现金偏移法交叉验证结果一致。北交所历史不含 prevclose，无法推导，失败时告警。

### 数据的最终性（何时可用）

11. 日线在北京时间 **16:00** 之后才视为最终。此前运行时，当天交易日不进入本次采集，因为科创板、创业板盘后固定价格交易持续到 15:30。
12. 增量运行总是重新下载最近 3 个交易日，供应商事后修订的数据会覆盖旧行。
13. 全市场快照按**抓取时间**标注交易日；盘中抓取的快照不写入标准层。

### 证券状态的时间点

14. **停牌**：采集东方财富数据中心每次运行的快照（只保留每只股票最近一次停牌）和百度停复牌日历（2023-01-03 起逐日），合并为 `suspension_events`，只追加不覆盖。无日线的交易日在 `bar_gaps` 中标记是否能被停牌事件解释。2023 年以前的缺口大多是停牌，但没有外部事件可以印证。
15. **风险警示（ST/\*ST/退市整理）**：三个交易所都有带生效日期的区间（`risk_warning_intervals`）。
    - 深市：交易所简称变更历史（`source = szse_name_change`）；
    - 沪市、北交所：由交易所公告推导（`source = sse_bulletin` / `bse_announcement`），方法见文末补充；
    - 只有在市证券名称带 ST、却没有任何带日期区间覆盖时，才保留"仅当前状态"的兜底记录（`source = current_name`，起始日期未知，回测不使用），并在审计中告警。

## 未决事项

## 补充（2026-09-26，阶段 2）

- **主板风险警示股票涨跌幅**：2026-07-05 前为 5%，**2026-07-06 起为 10%**（2026-04-24 发布修订规则，2025-06-27 的只是征求意见稿）。数据中 ST 股的最大涨跌幅正好在当日由约 5% 跳到约 10%。规则已写入 `configs/market_rules/cn_a_share.json`。
- **`factor_as_of` 的含义**：它是整份因子快照的有效截止日（一次运行里所有行相同），不是每个除权事件的发布时间。回测在 T+1 开盘前使用当日除权步长，这是允许的，因为除权除息方案在除权日之前已经公告。
- **回测中的后复权因子**按完整交易日历取 as-of 值，停牌期间发生的除权也会在除权日调整持仓（见 ADR-002 §4）。

## 风险

- 前复权价格水平不是时间点数据，任何以价格水平为阈值的规则都必须按第 4 条处理，否则会引入未来数据。
- 后复权因子的绝对水平取决于上市以来是否记录了全部事件；推导来源（689009）只保证窗口内的比值正确。
- 百度日历的反爬策略可能变化；东方财富快照会覆盖自身历史，所以必须每次运行都采集。

## 复审条件

更换数据源、引入财务数据（需要"公告时间"规则），或交易所公告检索接口变化时复审。

## 补充（2026-09-26）：沪市、北交所 ST 历史

### 数据源

- **上交所**：官网公司公告检索（`query.sse.com.cn/security/stock/queryCompanyBulletinNew.do`），按季度窗口抓取标题含"风险警示""退市整理"的公告（2013 年起；该服务超过约一个季度的窗口不返回结果）。2021 年起，每条公告都带发布当时的证券简称。
- **北交所**：官网公告检索（`bse.cn/disclosureInfoController/companyAnnouncement.do`），按年度窗口抓取（2021-11-15 起）。
  - 2025 年以前的旧代码（43/83/87 开头）映射到 920 开头的新代码时，要求"920 + 后三位"存在于证券主数据中，且公司名称一致；
  - 映射不上的公告丢弃并计数，其中包括查询结果里混入的新三板公司。
- 原始响应按窗口保存在原始层，标准层为 `risk_warning_bulletins`，抓取记录为 `bulletin_fetch_log`。
- 每份公告以文件地址为唯一标识：上交所 `URL`，北交所 `destFilePath`。上交所的 `ORG_BULLETIN_ID` 是整个披露包共用的编号，同一天发布的实施公告和董事会说明等文件编号相同，不能用来去重（曾因此丢失 220 份公告，其中包括 603039 的实施公告）。
- 最近 120 天内的窗口每次运行都重新抓取，以吸收补发的公告；上交所每页请求之间停顿 3 秒、每页最多尝试 2 次；同一交易所连续 2 个窗口失败后，剩余窗口推迟到下次运行（上交所有反爬限流）。

### 推导（`data_platform/risk_history.py`）

1. **标题分类**：解析为两个独立标志，"退市风险警示"对应 \*ST，"其他风险警示"对应 ST。
   - 忽略的标题：提示性公告、进展公告、申请、回复、"可能被实施"等。
   - 支持的写法：叠加实施、撤销后继续实施、撤销部分其他风险警示、因重整被实施等。
2. **生效日期**：交易所在实施日停牌一天，新简称从停牌后的第一个交易日起生效。
   - 上交所：停牌日为公告日当天或之后的第一个交易日；
   - 北交所：公告在晚间发布，停牌日为次一交易日。
   - 有日线时按实际停牌缺口确定生效日；没有日线时按一天停牌推算。
   - 同一变更的多份公告（董事会公告、"暨停牌"公告等）合并为停牌证据最强的一份。
3. **退市整理**："进入退市整理期"公告之后为退市整理期（`status = DELISTING`），到交易所退市日结束。
4. **名称证据修正**：公告上带日期的简称，以及标题前缀"ST xx关于……"，可以纠正漏掉的公告和首条事件之前的初始状态。
   - **状态变更公告，以及同一公司当天随之发布的其他文件，带的都是变更前的旧名称，不作为证据**。
5. **价格证据修正**（上交所主板 2026-07-06 之前，此时风险警示股的涨跌幅为 5%）：
   - 正常交易日（非复牌首日、上市满 5 根日线）成交超出 5% 范围，说明当天不是风险警示；
   - 收在 5% 涨跌停价、且当天没有越界，是风险警示的支持证据；某一侧只有 1–2 个支持日时视为巧合。
   - 据此推迟开始日、提前结束日或删除区间；对于只知道"最晚开始于某日"的区间，把开始日提前到不确定窗口内最后一次越界之后。
   - 每一处修正都记录在 `risk_warning_adjustments`。

### 验证（正式数据，独立于建模过程的证据）

| 检查 | 结果 |
|---|---|
| 2026 年快照、原始证券列表和当前名称，与模型状态对照 | 34,403 次比对，0 处不一致 |
| 上交所主板风险警示交易日（2020-01 至 2026-07）中，超出 5% 范围的天数 | 90,889 个交易日中 0 天 |
| ±5% 一字板落在风险警示区间之外 | 3,453 次中仅 5 次，全部是 600182（未完成股改的 S 股），已在市场规则中加入个股 5% 涨跌幅 |

- 这两项检查已加入每次运行的全量审计：快照名称对照，以及价格区间一致性。
- 回测据此把上交所、北交所的风险警示状态视为"已知"，不再使用"开盘价恰为 ±5% 推断锁板"的兜底规则。

### 局限

- 科创板和北交所的风险警示股涨跌幅与普通股相同，没有价格证据可用，只能依靠公告和名称证据。
- 2020 年以前的生效日期没有日线佐证，按一天停牌推算。这些日期只影响 2020 年初的初始状态，并已由价格证据校正。
