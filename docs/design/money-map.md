# 钱去哪地图（第一版）设计草稿

状态：方案已确认（2026-10-07），待开发。调研和回测见 `WORKLOG_2026-10-06.md`，主播视频要点见 `tools/xet/notes_episode18_money_map.md`（仓库外）。

## 1. 目标

每晚收盘后，用一张图回答"市场的交易集中在哪些行业、哪些行业过热该减、哪些行业涨起来了但还不拥挤"，并附上历史上同类状态之后的表现。

**范围**
- 只做申万一级 31 个行业。
- 第一版只做行业地图和历史统计，外加仓位管家的行业拥挤提醒。

**不含**（以后再做）
- 金边（券商上调盈利预期）和预期信号；
- 公司在买（回购、增持）和减持；
- 个股下钻；
- 市场宽度。

## 2. 数据

**新数据集 `sw_index_bars`**
- 内容：31 个申万一级行业指数的日线，包括开、高、低、收、成交量、成交额。
- 来源：申万官网，通过 AKShare `index_hist_sw` 获取，服务器上实测可用。每次返回全部历史，每晚 31 次请求。
- 起始日：16 个行业从 1999-12-30 起，12 个从 2014-02-21 起；石油石化、美容护理、环保这 3 个是 2021 版新设的行业，从 2021-12-13 起。
- 原始层存每次的返回；标准层按指数代码分区，可从原始层重建。
- 质量检查：最新日期等于预期交易日；成交额大于 0；日期属于交易日历。
- 待确认：成交额的单位（只影响显示，不影响占比）。

## 3. 计算

**定义**

| 量 | 算法 |
|---|---|
| 成交占比 s | 行业指数当日成交额 ÷ 当日 31 个行业成交额之和（2021-12 之前是 28 个） |
| 拥挤度 C | s 的近 20 日均值 ÷ s 的近 750 日均值（至少要有 675 日） |
| 3 个月涨幅 | 指数收盘价 60 个交易日的变化 |
| 12 个月涨幅 | 指数收盘价 250 个交易日的变化 |
| C 的 60 日变化 | 今日 C − 60 个交易日前的 C |

- 用主播屏幕上的 12 个数值核对过：C 的平均误差 0.013，涨幅一致。
- 历史不足 3 年的行业（2021 版新设的 3 个，到 2024 年底前）要标注出来。

**区域**

区域边界沿用主播的划分；页面要说明，这几条边界是照搬的，没有经过优化。

| 区域 | 条件 |
|---|---|
| 必须减 | C > 1.8 |
| 钱在打架 | 0.8 ≤ C ≤ 1.4，且 12 个月涨幅 > 15% |
| 刚开始动 | C < 0.8，且 12 个月涨幅 15%–50% |
| 没到时间 | C < 0.8，且 12 个月涨幅 < 15% |
| 其他 | 不在以上区域 |

**周快照（用于回放）**
- 每周最后一个交易日存一份：每个行业的 C、ΔC60、3 个月和 12 个月涨幅、区域、成交占比。

**历史统计（按格子）**
- 格子：C 分档（<0.8、0.8–1.4、1.4–1.8、>1.8）× 12 个月涨幅分档（<15%、15–50%、>50%），共 12 格。
- 统计项：每格之后 13 周、26 周相对 31 个行业平均和相对沪深300 的平均超额收益、跑输比例、样本数。
- 时间点规则：回放到第 t 周时，只用到第 t 周为止已经走完远期窗口的样本，也就是"那时候能知道的统计"。
- 另外单独统计"首次进入 C > 1.8"事件，两次进入之间至少隔 13 周。
- 10-06 回测（2016-12 至 2026-09）的参考值：
  - C>1.8 首次进入 61 次：之后 13 周相对行业平均 −2.6%（65% 跑输），相对沪深300 −4.1%（68% 跑输）；
  - C 在 0.8–1.4、12 个月涨幅 >50%：之后 13 周 +5.2%，26 周 +9.1%。

**运行**
- 每晚由日常流程在采集之后计算一次，结果缓存起来供页面读取，不在请求时重算。

## 4. 页面（看盘与仓位 → 钱去哪地图）

- **主图**：横轴是 12 个月涨幅，纵轴是拥挤度 C。
  - 每个行业一个气泡，大小按成交占比；
  - 带最近若干周的尾迹；
  - 画出四个区域。
- **时间轴**：可以拖动，也可以自动播放；默认显示最近 156 周，可以选更长。
- **右侧面板**：
  - "该减"：C > 1.8 的行业，附该事件的历史统计；
  - "值得看"：钱在打架区的行业，并按 12 个月涨幅排序；
  - 其余行业折叠。
- **悬停**：显示行业的 C、ΔC60、3 个月和 12 个月涨幅、所在格子，以及该格子的历史统计（只用当时之前的数据）。
- **点击行业**：
  - 高亮这个行业的尾迹；
  - 下方显示它的 C 走势和相对沪深300 的强弱走势。
- **页面说明**：
  - 拥挤度衡量的是交易热度，不是资金净流入；
  - 它是背景和减仓提示，不是买卖指令。

## 5. 仓位管家联动

- **对应行业**：标的按 `industry_sw` 当前的申万一级行业对应。
- **两种提醒**：
  - 所在行业 C 上穿 1.8：提醒"行业拥挤"，列入日报的"今日触发"；
  - 回落到 1.4 以下：提示"拥挤解除"。
- **阈值**：两个阈值放在仓位管家设置里，默认 1.8 和 1.4。
- **显示**：看板行和标的详情显示所在行业当前的 C 和区域。
- **推送**：只推送数量，和现有约定一致。
