# 钱去哪地图（第一版）设计

状态：已在 `money-map` 分支实现（2026-10-07）；调研和回测见 `WORKLOG_2026-10-06.md`；使用说明见 `docs/guides/money-map-guide.md`。

## 1. 目标与范围

每晚收盘后，用一张图回答：
- 市场的交易集中在哪些行业；
- 哪些行业过热该减；
- 哪些行业涨起来了但还不拥挤。

图上还附有历史上同类状态之后的表现。

**第一版包含**：
- 申万一级 31 个行业的地图和历史统计；
- 仓位管家的行业拥挤提醒。

**不含（第二版再定）**：
- 金边（券商上调盈利预期）和预期信号；
- 公司在买（回购、增持）和减持；
- 个股下钻；
- 市场宽度。

## 2. 数据：`sw_index_bars`

- **来源**：申万宏源官网的 31 个申万一级行业指数日线（AKShare `index_hist_sw`），代码表在 `data_platform/sw_index.py`。
- **请求方式**：每次请求返回全部历史，每晚 31 次请求，挂在采集的"指数"步骤之后（配置 `download_sw_indices`，起始日 `sw_index_start`）。
- **单位**：源数据的成交量是亿股、成交额是亿元，标准化时都乘以 1 亿，存成股和元。
- **各指数起始日**：16 个从 1999-12-30 起，12 个从 2014-02-21 起；石油石化、美容护理、环保这 3 个是 2021 版新设的，从 2021-12-13 起。
- **校验**：沿用指数日线的检查（价格合理、最新日不倒退）。
  - 不通过的那次返回存到原始层的 `sw_index_bars_rejected`，已有历史不动，重建时也不会重放它。
  - 下载失败、被拒或还没有最新日的数据都只记警告，因为这份数据只用于看图，不进入决策。
- **重建**：`rebuild` 从原始层逐次重放，结果和直接采集的一致（有测试覆盖）。
- **待观察**：申万每天什么时候公布当日数据。如果晚于每日流程的 18:17，当天的数据要到下一晚才进来。

## 3. 计算（`analytics/money_map.py`）

**基础量**

| 量 | 算法 |
|---|---|
| 成交占比 s | 行业指数当日成交额 ÷ 当日各行业成交额之和 |
| 拥挤度 C | s 的近 20 日均值（至少 15 日）÷ s 的近 750 日均值 |
| 3 个月、12 个月涨幅 | 指数收盘价 60、250 个交易日的变化 |
| ΔC60 | C 与 60 个交易日前的差 |

- **起算日**：面板从 28 个行业指数都有数据的那天开始，即 2014-02-21，这样各行业的占比基数一致。
- **显示与统计**：750 日均值有 250 日数据就开始显示 C（此时标"历史不足 3 年"）；满 675 日才进入历史统计。
- **核对**：和主播屏幕上的 12 个数值核对过，C 的平均误差为 0.013，涨幅一致。

**区域**（边界照搬主播图上的方框，没有为回测调过）

| 区域 | 条件 |
|---|---|
| 必须减 | C > 1.8 |
| 钱在这里打架 | 0.8 ≤ C ≤ 1.4，且 12 个月涨幅 ≥ 30% |
| 刚开始动 | 0.6 ≤ C < 0.8，且 12 个月涨幅 15%–50% |
| 没到时间 | C < 0.8，且 12 个月涨幅 < 15% |
| 其他 | 以上都不是 |

**统计格子**：拥挤度分 4 档（<0.8、0.8–1.4、1.4–1.8、>1.8）× 12 个月涨幅分 4 档（<15%、15–30%、30–50%、>50%），共 16 格。每个区域都由整格拼成。

**每周快照**：每周最后一个交易日取一次（最新一周可能还没结束）。

**远期超额收益**：每个周样本都算之后 13 周、26 周的两种超额收益：
- 相对 31 个行业的平均；
- 相对沪深300。

**时间点统计**：
- 第 t 周的统计只用远期窗口在 t 周之前已经走完的样本，即"那时能知道的统计"。实现方法是按"窗口走完的那一周"做累计和。
- 统计分三类：按格子、按区域，以及"首次进入 C > 1.8"事件（同一行业两次进入之间至少隔 13 周）。
- 有测试保证：截掉 t 之后的数据，t 时的统计不变。

**参考结果**（2016-12 至 2026-09）：
- 首次进入 C>1.8 共 60 次：之后 13 周相对行业平均 −2.6%（65% 跑输），相对沪深300 −4.1%（68% 跑输）。
- "钱在打架"区：之后 13 周 +4.2%，26 周 +6.5%。

**速度**：整张周表加全部统计，计算不到 0.2 秒。

## 4. 接口与页面

**查询层**（`app/money_map.py`）
- `MoneyMapQueries` 按行情库文件的修改时间缓存计算结果。
- 网页接口和仓位管家通过 `money_map_for(database)` 共用同一份结果。
- 行情库里没有 `sw_index_bars` 时返回 503，并把"缺数据"这个结论也缓存下来。

**接口**
- `GET /api/v1/moneymap?weeks=156`：返回周快照（`weeks=0` 为全部历史），每周附该周在场格子、区域和"首次进入"事件的统计。
- `GET /api/v1/moneymap/industries/{code}`：返回一个行业的日度拥挤度、成交占比、收盘价和相对沪深300 的强弱。

**页面**："看盘与仓位 → 钱去哪地图"（`views/market/money-map.vue`）。

- **气泡图**：横轴是 12 个月涨幅，纵轴是拥挤度，气泡大小按成交占比。
  - 底色画出四个区域。
  - 每个气泡带近 8 周的尾迹；选中的行业显示近 26 周的轨迹。
  - 坐标范围随所在周和尾迹自动调整，刻度落在整数位上。
- **配色**：只按区域着色——必须减用红色并画成三角形，钱在打架用蓝色，刚开始动用青色，其余用灰色。两套主题都用可视化规范的校验脚本检查过；因为暗色主题下红色和青色对色弱读者接近临界，所以加了形状区分。
- **回放**：时间轴可以拖动或自动播放，范围可选近 3 年或全部。
- **右侧**：分区列表，附该区的历史统计。
- **下方**：
  - 选中行业的两张小图（拥挤度、相对沪深300），上下排列、共用时间轴，不用双纵轴；
  - 该周的格子统计表，也是图的文字版。

## 5. 仓位管家联动

- **对应行业**：个股按 `industry_sw` 最新一条记录的一级行业名，对应到申万指数代码。指数和 ETF 不参与。
- **提醒事件**：由 `crossings` 根据日度 C 生成。

| 事件 | 触发 | 规则名 | 优先级 |
|---|---|---|---|
| 行业拥挤 | C 上穿 `crowd_high` | `industry_crowded` | 持有时 2（减仓），否则 4（提示） |
| 拥挤解除 | 拥挤之后 C 回落到 `crowd_low` 以下 | `industry_relief` | 4（提示） |

- **去重**：去重键是 `industry:{code}:{kind}:{日期}`。和其他提醒一样，只存"上次评估之后"的事件，所以新加的标的不会补出历史上的提醒。
- **设置**：`pm_settings.crowd_high`、`crowd_low`（迁移 0008），默认 1.8、1.4，在"规则设置"里修改，要求 0.5 ≤ 解除线 < 提醒线 ≤ 5。
- **显示**：看板和标的库多一列"行业拥挤度"，在必须减区时带"拥挤"标签，点击跳到地图。
