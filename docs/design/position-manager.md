# 仓位管家（一期）设计

参考：用户提供的《仓位管家》方法论（`C:\Users\Administrator\Desktop\GP\files\`，六册），以及 2026-09-30 的讨论与回测。

## 1. 目标

用户用技术分析判断个股处在哪个阶段，并画出结构（颈线、量度目标）。系统做以下几件事：
- 每天收盘后用日线做数学比较，到点提示入场、减仓、离场，并记录全过程；
- 给出四阶段的"系统观点"，供用户确认方向标签；
- 用历史数据回测阶段判断，参数可调。

系统**不下单**，也**不接入现有的多因子每日决策和模拟账户**。收益只记"按规则全执行时的模拟收益"。

## 2. 原则（沿用方法论的铁律，并做适配）

| # | 原则 | 本系统的做法 |
|---|---|---|
| ① | 行情判断由人做 | 方向标签由用户确认。系统观点只作参考，默认模式下一键采纳；也可切换为"纯手工"模式，不显示系统观点 |
| ② | 价位经确认才生效 | 画线、自动形态、手工输入都只产生候选；确认后写入价位表，并带版本 |
| ③ | 信号只用日线收盘价 | 规则引擎只读日线 |
| ④ | 质地评分不触发信号 | 一期不做质地评分 |
| ⑤ | 不接交易接口 | 只提示、只记录 |

## 3. 方向标签与系统观点

**标签**：右侧、筑底、左侧、顶部、未定。其中"顶部"是本系统新增的：持仓的退出规则继续起作用，但不再产生新的入场。

| 标签 | 规则层 | 展示 |
|---|---|---|
| 右侧 | 全部规则启用 | 完成度、阶梯、止盈 |
| 顶部 | 只有退出规则（阶梯、止盈、假突破、头部颈线），不入场 | 同右侧，加"顶部"徽章 |
| 筑底 | 只做筑底判据提示，不产生买入 | 形态与筑底判据 |
| 左侧 | 全部休眠 | 距起涨区还有多远 |
| 未定 | 不评估 | — |

**系统观点**采用 Weinstein 四阶段：1 筑底、2 右侧、3 顶部、4 左侧。
- 以长期均线的方向和价格相对均线的位置来判断；
- 新阶段要持续若干天才切换，避免来回跳；
- 附带理由，例如"200 日均线 20 日内 +2.1%，收盘在均线上方 6%，已持续 34 天"。

**参数**（每个用户可选方案，也可逐项修改）：

| 参数 | 稳健（默认） | 经典 | 短线 |
|---|---|---|---|
| 均线周期 | 200 | 150 | 60 |
| 斜率回看 | 20 | 20 | 10 |
| 个股走平阈值 | 1.5% | 2% | 2% |
| 指数走平阈值 | 0.6% | 0.6% | 0.6% |
| 均线附近区间 | ±3% | ±3% | ±3% |
| 确认天数 | 10 | 5 | 3 |
| 首段判断回看 / 涨幅 | 250 日 / 50% | 同 | 同 |

2020-10 至 2026-09 的回测结论，重跑见阶段回测页：
- 四阶段单独作为买卖信号没有优势；
- 大盘闸门有效：沪深300 处于左侧时出现的突破，60 日超额 −4% 到 −7%；
- 文档的判据②（缩量后放量阳线）是最好的入场过滤条件；放量突破反而更差。

## 4. 筑底判据（筑底标签下，命中任一条即提示复核）

1. 收盘站上用户新画的颈线；
2. 缩量企稳后放量阳线：近 N=10 日均量低于前 M=20 日均量的 70%，之后出现量 ≥ k=2 倍均量的阳线（均量不含当天）；
3. 二次探底不破前低：前低 = 进入筑底以来的最低收盘；前低之后反弹 ≥5%，且当日收盘不破前低。

同一判据提示过一次后，"维持筑底"期间不再重复提示。用户点确认后，标签转为右侧。

## 5. 结构与价位

- **一轮结构 = 颈线 + 量度目标**。同一标的可以有多轮，旧轮归档。
- **价位类型**：颈线、量度目标、头部颈线、起涨区（上沿和下沿）、回撤买入区（上沿和下沿，二期）、参考线。
- **来源**：看盘画线（选中后"设为……"）、自动画线识别的形态（采纳其颈线和目标）、手工输入。
- **版本**：修改后生成新版本，旧版本保留；与现行版本完全相同的保存不生成新版本。
- **生效日**：确认当日所在的交易日。规则的扫描起点是生效日，与日线历史的深度无关（方法论的护栏）。
- **失效线**：颈线 × 0.95，不单独存储。

**结构生命周期**（只看收盘价，与是否持仓无关）：

```
待突破 ──首个收盘 > 颈线──→ 进行中 ──峰值完成度 ≥ 90%──→ 已兑现 ──自峰值回撤 ≥ 15%──→ 已衰竭（终态）
```

- 完成度 =（收盘 − 颈线）/（目标 − 颈线）
- 结构峰值 = 激活后的最高收盘价

## 6. 规则（参数全部可调，默认值取自方法论）

**评估顺序**（同一标的同一天）：
1. 标签闸门：左侧、未定时静默；筑底时只做筑底判据；
2. 假突破清仓：持有时收盘 < 颈线 × 0.95（P1）；
3. 头部颈线跌破：处于"先观察"状态时收盘跌破头部颈线（P1）；
4. 移动止盈：完成度曾 ≥ 70% 后，自最高收盘回撤 ≥ 20%，清仓（P1）；
5. 阶梯减仓（P2）：完成度 ≥ 70% 时剩 70%，≥ 80% 时剩 50%，≥ 90% 时剩 25%；
6. 到达目标终减（P2）：
   - 主指数完成度 ≥ 90% 或已兑现：剩 10%；
   - 70%—90%：剩 15%；
   - < 70%：剩 20%；
   - 主指数结构已衰竭：剩 10%；
7. 共振入场（P3）：收盘 > 颈线，主指数标签为右侧，且本轮尚未入场。
   - 主指数完成度 ≥ 90% 时半仓，未录价位时满仓，并注明"指数完成度未知"；
   - 主指数不是右侧时，进入"待共振"，不放行；
8. 顶部观察提示：完成度 ≥ 90% 或到达目标当日（P4）；
9. 筑底判据（P4）。

**主指数**：
- 个股默认按板块和成分选择：科创板用科创50，创业板用创业板指，其余按沪深300、中证500、中证1000 成分，都不在时用中证1000。用户可以修改。
- 主指数自己也是一个标的，可以有标签和结构。
- 主指数的标签未设置时，入场闸门看主指数的系统观点。

**信号去抖**：同一标的、同一规则、同一价位版本、同一档位只触发一次。

**头部确认**：用户画头部颈线后二选一：
- "立即确认"：产生 P1 清仓提示，本轮战役结束；
- "先观察"：收盘跌破头部颈线时产生 P1 警报，用户确认后清仓。

## 7. 模拟战役

- 入场满仓或半仓，然后按各档比例减仓，清仓时全部卖出。
- 用历史收盘价计算整轮收益率。一轮中间假突破清仓后又重新入场的，分段记录，整轮收益为各段复合。
- **剧本收益**：从颈线走到目标的涨幅，作为"按剧本走完"的前瞻。
- **历史回放**：给定标的，从价位生效日起逐日重演，输出事件序列（日期、收盘、事件、动作、剩余仓位）。
- **"假设回放"**：把价位的生效日设在过去，就能验证规则在历史上会怎样。

## 8. 数据与接口

**业务库新表**（迁移 0006，全部带 `user_id`，按用户隔离）：

| 表 | 内容 |
|---|---|
| `pm_items` | 标的库：代码、类型（个股/指数/ETF）、分组、星标、方向标签、标签来源（手工/采纳系统观点）、主指数、备注、归档 |
| `pm_levels` | 价位：类型、价格、下沿、轮次、版本、状态（现行/已替代）、来源、生效日、确认时间 |
| `pm_signals` | 信号：日期、规则、优先级、档位、去抖键、内容、已读 |
| `pm_settings` | 每个用户的阶段参数方案与改动、规则参数、标签模式 |

结构状态、战役和回放都由规则引擎从价位和日线**即时算出**，不单独存储，保证"改了价位就重算"。

**接口**（`/api/v1/pm/*`）：
- 标的的增、删、改和批量导入；
- 标签的设置和采纳；
- 价位的确认和查询；
- 头部确认；
- 看板、突破清单、头部清单；
- 信号标记已读；
- 参数设置；
- 阶段观点（单只和批量）；
- 阶段回测（后台任务）；
- 标的回放。

**每日作业**：数据更新完成后，评估每个用户的全部标的，生成当天的信号，并推送日报（沿用现有通知渠道，按五档排序）。

## 11. 二期（2026-10-04 确认）

范围：三条路与回撤区、池子、哨兵、日报五档与清单完善、质地评分。

不做：
- 截图识别；
- 港股、美股、融资和期权；
- 推送仍只发条数，不发证券名称（共用渠道，见 §9）。

一期的原则全部沿用：标签压制规则，价位由人确认，质地分不触发任何信号。

### 11.1 结构走完之后：三条路

**选路建议**：一轮结构衰竭，或本轮离场（移动止盈、头部确认）以后，详情页按最新收盘相对本轮的位置给出建议，由用户选择。

记回撤比例 = (峰值 − 收盘) / (峰值 − 颈线)：

| 条件 | 建议 | 预填 |
|---|---|---|
| 收盘 ≥ 峰值 × 0.95 | 路 C 新高突破 | 第二轮颈线 = 本轮峰值，目标由你画 |
| 回撤比例 ≤ 50% | 路 A 浅回撤候买回 | 回撤区 = 峰值回撤 38.2%～50% 的区间，买回 5 成 |
| 其余 | 路 B 深蹲候形态 | 起涨区 = 颈线 ～ 颈线 × 1.1；第二轮目标默认前一轮峰值 |

预填只是起点，确认前可以改（价位必经确认，§2 ②）。

**新价位类型"回撤买入区"**：上沿、下沿，再加买回成数。属于当前轮，按版本保存，与其他价位相同。

**规则**（编号接 §6 的评估顺序）：

| 规则 | 条件 | 动作 |
|---|---|---|
| 回撤买回（P3） | 标签右侧，本轮未持有，收盘进入回撤区（下沿 ≤ 收盘 ≤ 上沿） | 提示"回撤到位，买回 N 成"，剧本仓位变为 N 成。主指数晚期（完成度 ≥ 90% 或已兑现）时照发，但标红"逆共振"，不拦截 |
| 买点作废（P3） | 未买回时，收盘 < 下沿 × 0.95 | 提示"买点作废"，回撤区失效 |
| 买回后清仓（P1） | 收盘 < 下沿 × 0.95；或自买回后最高收盘回撤 20%（与移动止盈同一参数） | 清仓 |
| 左侧→筑底（P4） | 标签左侧，收盘进入起涨区（收盘 ≤ 上沿） | 标签自动改为筑底（来源"自动"），提示"到达起涨区，开始盯形态"。规则设置里可以关掉 |

**文档前后不一致的地方**：方法论第一章说"触及哨兵也自动转筑底"，第七章和蓝图 2.8 说"哨兵只提醒，永不自动改标签"。采用后者：只有收盘进入**起涨区**会自动改标签。

### 11.2 池子（由状态推出，不需要记账）

| 池 | 条件（按顺序取第一个满足的） |
|---|---|
| 归档 | 已移出标的库 |
| 持有 | 剧本仓位 > 0 |
| 回撤关注 | 未持有，当前轮有未失效的回撤区 |
| 就绪 | 已画颈线和目标，结构待突破或已突破未入场，标签为右侧或筑底 |
| 观察 | 其余 |

看板和标的库都可以按池筛选。池子与方向标签正交：标签是"山的哪一边"，池子是"手上什么状态"。

### 11.3 哨兵

- **数量和内容**：每个标的最多 2 条。每条记价格、方向（向上站上 / 向下到达）和引用来源（颈线、起涨区上沿或下沿、前高、失效线、手工）。
- **价格口径**：与价位相同，按后复权保存，按前复权显示。
- **距离**：哨兵 / 收盘 − 1。
- **路程**：|距离| ÷ 近 20 日平均振幅（(最高 − 最低) / 前收），写作"约 N 天"。这是"提前几天提醒"在数学上最诚实的说法。
- **穿越**：收盘穿越时提示 P2"收盘站上（或跌到）哨兵 x，是否更新方向标签？"。之后这条哨兵记为已穿越，可以重设，同一天也可以。**哨兵永不改标签。**
- **图上**：蓝色点划线，标签为"⚓哨兵 价 ↑/↓"，可以拖动改价。

### 11.4 日报五档与看板提示栏

| 档 | 内容 |
|---|---|
| 1 今日触发 | 最新交易日的信号：清仓和假突破置顶，其后是入场、减仓、回撤买回 |
| 2 临门一脚 | 距下一个触发价 ≤ 3%：下一档减仓价、颈线、回撤区上沿、哨兵 |
| 3 逼近中 | 距离 3%～8% |
| 4 有变化 | 完成度比上一交易日变化 ≥ 10 个百分点，或结构状态、池子有变化 |
| 5 其余 | 汇总成一行 |

- 同一档内按星标、再按质地排序。
- 看板的提示栏按这五档排列。
- 外部推送只发各档条数。

### 11.5 清单完善

**突破确立**分两组：
- 已共振：已入场，半仓入场的在行内注明；
- 待共振：已突破，写明在等什么。

每行显示：突破日、突破价、现价涨跌、距突破位、完成度、主指数状态、剧本收益、质地。页底列出近 7 天移出的标的，移出原因包括假突破、结构衰竭、头部确认、手动归档。

**头部确立**也分两组：
- 观察中：显示头部颈线价、现价、距离；
- 已确立：显示确认日、确认时价格、现价、确认后涨跌。确认后涨跌带 ±1% 的中性带：跌超 1% 算"判对"，涨超 1% 算"判早"，其余算中性。

**模拟战役总账**：
- 每只标的的每一轮各一行：入场、各段、离场、收益；
- 合计：轮数、胜率、平均每轮收益；
- 可以设杠杆系数，只影响显示。

一轮结构的回放到下一轮价位的生效日为止。

### 11.6 质地评分（只排序，不触发）

**六个维度**，每维 0～100 分：

| 维度 | 口径 | 分档 |
|---|---|---|
| PEG | 市盈率（TTM）÷（归母净利 TTM 同比 × 100） | < 0.5 得 100，< 1 得 80，< 1.5 得 60，< 2.5 得 40；更高、亏损或负增长得 15 |
| 营收同比 | 营收 TTM 同比 | ≥ 30% 得 100，≥ 15% 得 80，≥ 5% 得 60，≥ 0 得 45，≥ −20% 得 25；更低得 10 |
| 净利同比 | 归母净利 TTM 同比 | 同上 |
| ROE | 归母净利 TTM ÷ 平均净资产 | ≥ 20% 得 100，≥ 15% 得 85，≥ 10% 得 70，≥ 5% 得 50，≥ 0 得 30；为负得 10 |
| 毛利率趋势 | 毛利率 TTM 比一年前变化（百分点） | ≥ +3 得 100，≥ +1 得 80，≥ −1 得 60，≥ −3 得 40；更低得 20 |
| 业绩预告 | 近 6 个月最新一期净利润预告的类型 | 预增、扭亏得 100；略增、续盈得 75；减亏得 60；不确定得 50；略减得 30；预减、首亏、续亏、增亏得 10 |

**口径说明**：
- 财务指标沿用 ADR-004 的时间点规则（`fundamentals/pit.py`）：取最新交易日已知的值，一年前的值按一年前那天已知的取。
- 市值 = 不复权收盘 × 最新已知总股本。
- 银行、券商、保险没有营业成本，毛利率趋势这一维为空。

**总分和档位**：
- 总分 = 有数据的维度的平均，至少要有 3 维；
- A ≥ 75，B ≥ 60，C ≥ 40，D < 40；
- 只评个股，指数和 ETF 不评。

**计算和显示**：每晚作业为所有标的库里的个股计算一次，结果写入 `pm_quality`。页面显示档位、总分、六维子分和数据时点。

**新数据集 `earnings_forecast`**：
- 来源：东方财富 `RPT_PUBLIC_OP_NEWPREDICT`。
- 抓取方式与财报相同：
  - 按报告期抓，从 2020 年起；
  - 最近 4 个报告期每周重抓一次；
  - 近 45 天的公告日窗口每次都抓。
- 原始层保留全部字段。
- 去重键：(代码, 报告期, 预告科目, 公告日)。
- 可以从原始层重建。
