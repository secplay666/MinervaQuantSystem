# 仓位管家使用说明

- 适用：一期（2026-10）
- 设计：`docs/design/position-manager.md`
- 入口：左侧菜单"看盘与仓位"

仓位管家帮你按"结构 + 规则"管理个股、指数和 ETF 的仓位节奏：
- 方向由你确认；
- 系统给出阶段观点，按规则推演"剧本仓位"，并在规则触发时提示。

**系统不下单**。剧本仓位只是规则的推演，不是你的实际持仓。

## 1. 第一次使用

1. **标的库**：粘贴代码，空格、逗号或换行分隔均可，例如 `600000 600000.SH sh000300 510300`。可以放进分组。
2. **确认方向标签**：
   - 表格里的"系统观点"列是四阶段判断，悬停可以看理由。点"采纳"即用系统观点，也可以在下拉框里自己选。
   - 标签从当天（最新交易日）起生效。
3. **画结构**：
   - 打开 K 线（标的库里的"K 线"，或看盘页）。
   - 单击一条画线选中它，在右侧数据窗口"结构"栏里点"颈线"或"量度目标"，确认价格后保存。
   - 也可以在"自动分析"里对看涨形态点"采纳为结构"，或在标的详情页直接填价格。
4. **看板**：每个标的显示：
   - 结构进度和完成度；
   - 剧本仓位；
   - "在等什么"，例如"等主指数右侧""距颈线 +8%"；
   - 下一步的价位。

每晚数据更新后，系统会把当天触发的规则记成提示。

## 2. 标签

| 标签 | 规则 |
|---|---|
| 右侧 | 入场、减仓、退出全部生效 |
| 顶部 | 只做退出（阶梯、止盈、假突破、头部颈线），不再入场 |
| 筑底 | 只做筑底判据提示：①突破颈线；②缩量后放量阳线；③回踩不破 |
| 左侧 | 规则休眠，显示距起涨区还有多远 |
| 未定 | 规则休眠 |

想完全自己判断，可以在"规则设置"里切到"纯手工"，页面就不再显示系统观点。

## 3. 规则（默认值，可在"规则设置"里改）

**结构**：一条颈线加一个量度目标。

- 完成度 =（收盘 − 颈线）/（目标 − 颈线）。
- 进度依次为：待突破 → 进行中 → 已兑现（峰值完成度 90%）→ 已衰竭（兑现后回撤 15%）。

**入场**：收盘站上颈线，并且主指数是右侧。

- 主指数完成度到 90% 以后只建半仓。
- 主指数不是右侧时，提示"等待共振"。

**减仓**：

- 阶梯：完成度 70% 时留 70%，80% 时留 50%，90% 时留 25%。
- 到达目标时按主指数位置再减：主指数完成度不到 70% 留 20%，70%—90% 留 15%，90% 以上或已兑现留 10%。
- 确认结构时价格已经过了某一档，就直接按那一档建仓，例如已过 80% 只建 50%。

**清仓**：

- 假突破：收盘跌破颈线的 95%。跌破后再站上颈线，可以重新入场。
- 头部颈线：
  - 先观察：跌破后清仓；
  - 立即确认：当天清仓。
- 移动止盈：完成度曾到 70% 后，自持有期最高收盘回撤 20%，清仓，本轮结束。

**主指数**：入场闸门参考的指数，在标的库"编辑"里可以改。默认取法：

- 科创板 → 科创50；
- 创业板 → 创业板指；
- 沪深300、中证500、中证1000 的成分股 → 对应指数；
- 其他个股 → 中证1000；
- ETF → 它跟踪的指数。

指数本身也可以加进标的库、画结构，入场闸门会用你给指数的标签和完成度。

## 4. 价格和复权

- 在前复权、不复权或后复权图上确认的价位，系统都换算成后复权保存，所以除权以后不用重画。
- 页面上统一按前复权显示。
- 价位线只画在前复权图上；指数和 ETF 不复权，任何口径都会画。
- 改价位会生成新版本，旧版本保留。和当前版本完全相同的保存不算修改。

## 5. 阶段回测

在全市场（含已退市股票）上检验四阶段参数，结果包括：

- 各阶段之后的超额收益；
- 阶段切换之后的表现；
- 大盘闸门；
- 筑底判据的过滤效果；
- 分年统计。

一次回测要十几秒到一分钟，相同参数和数据会直接复用结果。

## 6. 推送和隐私

- 每个人的标的库、标签和结构只有自己能看到。
- "规则设置"里打开"每日推送"后，每晚有新提示时，系统会通过外部通知渠道发一条消息。消息里**只有条数**，例如"仓位管家：减仓 2 条（张三）"，不含证券名称，因为通知渠道和通知中心是大家共用的。详情在自己的仓位看板里看。
