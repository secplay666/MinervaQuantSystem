# 期权页面使用说明

菜单：**看盘与仓位 → 期权**（地址 `/options`）。

用来查看上交所 ETF 期权和中金所股指期权：
- 每个到期月份的全部合约；
- 任一合约（包括已经到期的合约）的历史日 K 线；
- 上交所合约的分时走势。

交易软件通常只显示在交易的合约，这个页面可以回看以前的合约。

## 2. 怎么用

1. **选标的和到期月份**。月份分两组：
   - “在交易”：默认选最近的一个；
   - “已到期”：从近到远排列，最早到 2015 年。
2. **选日期**。默认是该月份最后一个有行情的交易日。可以用“前一日 / 后一日”逐日翻，日期框里只能选有行情的日子。
3. **看 T 型报价表**：
   - 左边是认购，右边是认沽，中间是行权价；
   - 浅色底是实值合约：认购的行权价低于标的收盘，认沽的行权价高于标的收盘；
   - “平值”标签：行权价最接近标的收盘的一档；
   - “调”标签：标的分红后调整过的合约，行权价和合约单位都变了，代码末尾是 A、B 等字母。
4. **点任一合约的数字**，下方显示这个合约的走势：
   - **日 K**：分四层，从上到下是：
     - 合约 K 线，叠一条虚线表示内在价值；
     - 成交量；
     - 标的收盘，叠一条虚线表示行权价；
     - 上交所合约画隐含波动率，中金所合约画持仓量。
   - **分时**：所选交易日的 1 分钟价格和均价，虚线是前一日收盘，下面是每分钟成交量。可以切换日期。
   - 网址会带上当前的标的、月份和合约，收藏或发给自己可以直接打开。

## 3. 表里的数字

| 名称 | 含义 |
|---|---|
| 收盘 | 合约当天收盘价。上交所单位是元/份，一张 = 10,000 份；中金所单位是点，一张 = 每点 100 元 |
| 涨跌幅 | 相对前一个交易日收盘 |
| 成交量、持仓量 | 张。中金所来自交易所每日统计，2020 年起都有。上交所由分钟线汇总（成交量相加，持仓量取收盘那一分钟），所以从开始抓分钟线那天起才有，以前的日子显示“—” |
| 隐含波动率 | 交易所收盘后按收盘价反推的波动率，越高期权越贵；只有上交所有。深度实值、临近到期的合约常常反推不出来，显示“—”；到期日当天交易所不公布 |
| Delta | 标的涨 1 元（或 1 点）时期权价格大约变多少。上交所是交易所风险指标，中金所是交易所每日统计里公布的数值 |
| 内在价值 | 认购 = 标的 − 行权价，认沽 = 行权价 − 标的，小于 0 记为 0。也就是现在立刻行权能拿到的部分 |
| 时间价值 | 收盘价 − 内在价值。离到期越近越少，到期时归零，这就是买方每天在付的成本 |

## 4. 数据什么时候更新

- **每个交易日的数据在第二天早上 09:05 抓取**，和 ETF 份额的早上补抓一起运行（周二到周六）。所以早上 9 点多以后能看到前一个交易日的数据，傍晚看不到当天的。
- **分时数据只有一天的保存期**。数据源只保留最近一个交易日的分钟线，下一个交易日 09:30 开盘后就取不到了。
  - 所以分时从开始抓取的那天起才有，以前的合约没有分时；
  - 哪天早上补抓失败，那一天的分时就缺了，日线不受影响，下次补上。
- **中金所期权没有分时**：没有找到可用的免费来源。

## 5. 数据来源和局限

| 数据 | 来源 | 说明 |
|---|---|---|
| 上交所合约列表、隐含波动率、希腊字母 | 上交所风险指标（每天一个文件） | 2015-02-09 起 |
| 上交所日线 | 新浪财经，每个合约一次取全部历史 | 2015 年 2 月新浪缺收盘价，那几天的 K 线是空的。新浪的“成交量”不能用（10-09 核对：各合约加起来只有交易所公布总量的六成左右，大的数还会溢出），没有采用 |
| 上交所分钟线 | 新浪财经 | 见上节 |
| 中金所日线、持仓量、结算价、Delta | 中金所官网每日统计文件 | 2020-01 起 |
| 标的价格 | 系统已有的 ETF 日线（不复权）和指数日线 | |

**到期日**按交易所规则推算：
- 上交所是到期月第四个星期三；
- 中金所是第三个星期五；
- 遇到休市顺延到下一个交易日。

分红调整过的合约，内在价值按调整后的行权价计算。调整日以前，这个数会有一点偏差。

## 6. 提醒

- 页面只用来看行情，不是交易建议。
- 之前的研究（`docs/research/options-put-after-breakdown-2026-10.md`）发现，买认沽长期平均是亏的。比较可靠的规律只有一条：期权变贵或者指数跌够的时候卖出，好于拿到到期。
- 只做买方，最大损失是权利金。不要卖出开仓。
